Welcome to NGINX with Let's Encrypt!

This page is being served by NGINX in a Docker container with HTTPS support.

This NGINX instance is managed by the Elysia NGINX Controller.

This server is ready to use Let's Encrypt for free, automatically-renewed SSL certificates.

You can create, list, update, and delete subdomains through the API!

Note: For Let's Encrypt to work, your server needs to be publicly accessible on the internet with a valid domain name pointing to it.
